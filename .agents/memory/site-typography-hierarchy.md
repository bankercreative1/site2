---
name: Site typography hierarchy
description: The required semantic and visual heading system for SiteFlyer pages.
---

Use the shared responsive typography tokens for Display, H1, H2, H3, H4, editorial accent, eyebrow, body, and small text. The system must define deliberate desktop, tablet, and phone tiers. Page-specific CSS may control color, alignment, and spacing, but must not assign arbitrary heading sizes.

**Why:** Independent module and page-level sizes caused subsection headings to look stronger than their parent section titles. The user explicitly requires one consistent sitewide reference system.

**How to apply:** Use one H1 for the page title, H2 for major section titles, H3 for topics within those sections, and H4 for minor labels. Verify all three viewport tiers against `/style-guide/` before completing typography changes.

The style guide is a reference to measured production styles, not a redesign or speculative token proposal. It must show the actual Circe Rounded, Circe, and Circe Slab C roles alongside real site colors and components.
