---
name: Site typography hierarchy
description: The required semantic and visual heading system for SiteFlyer pages.
---

Use shared responsive tokens for page titles, section titles, subsection titles, editorial accents, eyebrows, body, and small text. HTML heading levels preserve structure, but the visible hierarchy must be determined by the content role. Page CSS may control color, alignment, and spacing, but must not flatten all titles into one treatment.

**Why:** Independent module and page-level sizes caused subsection headings to look stronger than their parent section titles. The user explicitly requires one consistent sitewide reference system.

**How to apply:** Keep rounded navy structural titles, light red slab editorial statements, red uppercase eyebrows, normal body copy, and smaller supporting text visually distinct. Do not globally force every rich-text paragraph to one size. Verify all three viewport tiers against `/style-guide/`.

Editorial slab text uses the accent color on light surfaces, but must switch to white on orange or navy panels. Always verify foreground and background together when applying a shared role.

The style guide is a reference to measured production styles, not a redesign or speculative token proposal. It must show the actual Circe Rounded, Circe, and Circe Slab C roles alongside real site colors and components.
