Rules

How to use the scale

  1. One H1 per page. It names the page and is always stronger than its sections.
  2. H2 starts a major section. “The (Not So) Fine Print” is an H2; its topics are H3s.
  3. Do not choose sizes per module. Use the shared token for the semantic level.
  4. Use the slab style as an accent, not a hierarchy shortcut. It never makes a lower-level heading larger than its parent.
  5. The scale is responsive. Desktop, tablet, and phone use deliberate sizes at the shared site breakpoints.
